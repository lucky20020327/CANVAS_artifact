# 实体类和对应仓储类的依赖代码

## ReaderAccount实体类代码

```cpp
class ReaderAccount {
 public:
  uint64_t reader_id() const;
  uint32_t account_status() const;
};

```

## ReaderAccount仓储类代码

```cpp
class ReaderAccountRepo {
 public:
  // Query one reader account by reader_id.
  // Returns an empty result when no record exists.
  ReaderAccount QueryByReaderId(uint64_t reader_id);
};

```
## CardOpeningRecord实体类代码

```cpp
class CardOpeningRecord {
 public:
  uint64_t reader_id() const;
  uint32_t removed_flag() const;
};

```

## CardOpeningRecord仓储类代码

```cpp
class CardOpeningRecordRepo {
 public:
  // Count records whose removed_flag is 0.
  uint32_t CountActive(uint64_t reader_id);
};

```
## AlternateDocumentReview实体类代码

```cpp
class AlternateDocumentReview {
 public:
  uint64_t reader_id() const;
  uint32_t review_allowed() const;
};

```

## AlternateDocumentReview仓储类代码

```cpp
class AlternateDocumentReviewRepo {
 public:
  // Query whether a non-standard document has passed review.
  // Missing records are treated as review_allowed = 0 by the caller.
  AlternateDocumentReview QueryByReaderId(uint64_t reader_id);
};

```
