# 实体类和对应仓储类的依赖代码

## ReaderAccount实体类代码

```cpp
class ReaderAccount {
 public:
  uint64_t reader_id() const;
  uint32_t account_status() const;
};

```

## ReaderAccount仓储类代码

```cpp
class ReaderAccountPoRouteKey {
 public:
  void set_reader_id(uint64_t reader_id);
};

class ReaderAccountRepo {
 public:
  // Query by reader_id within the supplied route.
  // Throw hostcomm::errorcode::DAO_GET_EMPTY_RECORD when no record exists.
  ReaderAccount GetByPrimaryKey(const ReaderAccountPoRouteKey& route, uint64_t reader_id);
};

```
