# 宿主框架使用说明（节选）

本文件只保留这个示例会用到的约定，用来说明工作区中框架指南的角色。

## 仓储调用

- 实体、路由键和仓储类型都位于 `entity_library` 命名空间；具体方法签名见实体依赖文件。
- `GetByPrimaryKey(route, reader_id)` 查询主键记录；`Count(route, removed_flag)` 统计路由范围内具有指定删除标记的记录。
- 查不到单条记录时抛出 `hostcomm::errorcode::DAO_GET_EMPTY_RECORD`；`uclient::MakeOutcome` 捕获调用结果或异常。
- `TryTakeException(code)` 仅消费匹配错误；`TakeResult()` 返回结果或重新抛出未匹配的异常。

- 按步骤文档中的路由字段查询，不要额外猜测查询条件。
- 查询单条记录且没有命中时，按该步骤的规则决定继续还是返回错误码。
- 统计数量时只计入步骤补充说明所允许的记录。

## 错误

- 只有规则表明确要求时才返回错误码。`UCLI_ERROR << message << code` 抛出该错误并终止当前调用，因此规则表按顺序实现时遵循首个命中规则的行为。
- 错误码使用当前接口自己的枚举，并带上规则中的说明。
- 引用错误码时包含开发需求中给出的头文件。

## 步骤间数据

- 在 `Process` 中用局部变量保存上游步骤的产出，再按数据边传给下游。
- 步骤函数之间不要互相调用。
