# 开发需求

## 一、开发目标

完成 `checkreadercardeligibility.cpp` 文件的实现。

**基本信息：**
- **模块（服务名）**：librarycarddomain
- **接口**：CheckReaderCardEligibility

**实现要求：**
- 编辑范围：仅在 handler 类的定义中完成所有代码实现
- 每个步骤（如果不是控制语句）实现为 handler 类中的成员函数，并在 Process 函数中调用
- 成员函数不能互相调用
- 成员函数只能使用当前步骤文档中提到的 API，不能使用其他步骤的 API
- 成员函数的签名需要参考其依赖的外部数据以及提供给外部的数据进行设计
- 控制语句（如 if、while、switch 等）直接在 Process 函数中实现，不需要单独的成员函数

## 二、待实现的 API 契约定义

### API Name: **LibraryCardDomain_CheckReaderCardEligibility**
Description:
  判断读者是否可以新办借书证

当前服务名称: librarycarddomain

Request: librarycarddomain.CheckReaderCardEligibilityReq
Response: librarycarddomain.CheckReaderCardEligibilityResp
### API的请求、响应涉及的所有结构体+枚举值的定义（Proto3语法）:

#### 1. Structure Name: librarycarddomain.CheckReaderCardEligibilityReq
Definition:
```protobuf
message CheckReaderCardEligibilityReq {
  uint64 reader_id = 1;
  string home_branch = 2;
  string document_type = 3;
  uint32 profile_complete = 4;
  uint32 max_open_cards = 5;
}

```

**reader_id**
- 中文名：读者编号
- 描述：【必填】读者编号
- 概念：ReaderId
- 最小值：1

**home_branch**
- 中文名：所属分馆
- 描述：【必填】分馆编码
- 概念：BranchCode
- 最小长度：4
- 最大长度：16

**document_type**
- 中文名：证件类型
- 描述：【必填】读者登记的证件类型
- 概念：DocumentType
- 枚举值：
        - 1（常用证件DOC_STANDARD）
        - 2（护照DOC_PASSPORT）
        - 3（其他证件DOC_OTHER）
        
**profile_complete**
- 中文名：资料是否完整
- 描述：【必填】0 表示资料未齐，1 表示资料已齐
- 概念：ProfileCompleteness
- 枚举值：
        - 0（未齐PROFILE_MISSING）
        - 1（已齐PROFILE_READY）
        
**max_open_cards**
- 中文名：办证上限
- 描述：【必填】同一读者允许同时持有的借书证数量上限
- 概念：OpenCardLimit
- 最小值：1
- 最大值：5


#### 2. Structure Name: librarycarddomain.CheckReaderCardEligibilityResp
Definition:
```protobuf
message CheckReaderCardEligibilityResp {
  uint32 eligible = 1;
  string denial_reason = 2;
}

```

**eligible**
- 中文名：是否可办证
- 描述：1 表示可以新办，0 表示不可以
- 概念：EligibilityFlag
- 枚举值：
        - 0（不可办理NOT_ELIGIBLE）
        - 1（可以办理ELIGIBLE）
        
**denial_reason**
- 中文名：拒绝说明
- 描述：不可办理时的说明；可以办理时为空
- 概念：DenialReason
- 最大长度：128



## 三、当前待开发的API新定义的错误码清单

以下是当前待开发的API新定义的错误码清单，在开发时需要严格根据需求在关键异常位置抛出以下错误码。

- 使用以下错误码时需要在代码中包含头文件: example/errorcode/ec_module_librarycarddomain.h
  1. 枚举 librarycarddomain::errorcode::INVALID_PARAM
     - 错误码描述: 参数不符合契约约束
  2. 枚举 librarycarddomain::errorcode::ACCOUNT_CLOSED
     - 错误码描述: 读者账户已关闭
  3. 枚举 librarycarddomain::errorcode::PROFILE_INCOMPLETE
     - 错误码描述: 读者资料未填写完整
  4. 枚举 librarycarddomain::errorcode::OPEN_CARD_LIMIT_REACHED
     - 错误码描述: 办证数量达到馆方上限
  5. 枚举 librarycarddomain::errorcode::DOCUMENT_REVIEW_REQUIRED
     - 错误码描述: 非常用证件需要先完成复核
