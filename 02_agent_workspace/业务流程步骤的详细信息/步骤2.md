// 使用Drools Rule Language (DRL)语法定义的规则表: 读者账户查询结果判断
rule "读者账户查询结果判断_规则0"

    salience 2
**when**

**end**

rule "读者账户查询结果判断_规则1"
    // 规则优先级，数字越大优先级越高

**end**
