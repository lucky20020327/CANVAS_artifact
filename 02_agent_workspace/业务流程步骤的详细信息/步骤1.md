
# 步骤1
## 步骤目标：校验入口参数

## 步骤1的业务规则（Drools DRL）：
// 使用Drools Rule Language (DRL)语法定义的规则表: 入口参数检查
rule "入口参数检查_规则0"
    // 最高优先级规则
    salience 1
**when**
"必填参数均已传入，并且满足概念上的取值约束" is **False**
**then**
返回码= 参数不符合契约约束(INVALID_PARAM)

**end**



## 步骤1的补充说明：
按开发需求中的入口字段契约检查必填值和取值范围；不满足时返回 INVALID_PARAM。
