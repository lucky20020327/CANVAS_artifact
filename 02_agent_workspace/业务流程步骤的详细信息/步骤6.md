### 依赖的数据结构定义

以下是当前步骤依赖的数据结构的完整定义：


#### `CheckReaderCardEligibility.request(CheckReaderCardEligibilityReq).profile_complete`


**profile_complete**
- 中文名：资料是否完整
- 描述：【必填】0 表示资料未齐，1 表示资料已齐
- 概念：ProfileCompleteness
- 枚举值：
- 0（未齐PROFILE_MISSING）
- 1（已齐PROFILE_READY）

#### `CheckReaderCardEligibility.request(CheckReaderCardEligibilityReq).max_open_cards`


**max_open_cards**
- 中文名：办证上限
- 描述：【必填】同一读者允许同时持有的借书证数量上限
- 概念：OpenCardLimit
- 最小值：1
- 最大值：5

#### `CheckReaderCardEligibility.request(CheckReaderCardEligibilityReq).document_type`


**document_type**
- 中文名：证件类型
- 描述：【必填】读者登记的证件类型
- 概念：DocumentType
- 枚举值：
- 1（常用证件DOC_STANDARD）
- 2（护照DOC_PASSPORT）
- 3（其他证件DOC_OTHER）


当前步骤没有任何提供给下游步骤的数据

## 步骤6的业务规则（Drools DRL）：
// 使用Drools Rule Language (DRL)语法定义的规则表: 新办借书证资格判断
rule "新办借书证资格判断_规则0"
    // 最高优先级规则
    salience 4
**when**
"读者账户未关闭" is **False**
**then**
返回码= 读者账户已关闭(ACCOUNT_CLOSED)
**end**

rule "新办借书证资格判断_规则1"
    // 规则优先级，数字越大优先级越高
    salience 3
**when**
"读者资料已填写完整" is **False**
**then**
返回码= 读者资料未填写完整(PROFILE_INCOMPLETE)
**end**

rule "新办借书证资格判断_规则2"
    // 规则优先级，数字越大优先级越高
    salience 2
**when**
"未删除的办证记录数量小于办证上限" is **False**
**then**
返回码= 办证数量达到馆方上限(OPEN_CARD_LIMIT_REACHED)
**end**

rule "新办借书证资格判断_规则3"
    // 规则优先级，数字越大优先级越高
    salience 1
**when**
"证件为常用证件，或非常用证件的复核已通过" is **False**
**then**
返回码= 非常用证件需要先完成复核(DOCUMENT_REVIEW_REQUIRED)
**end**
